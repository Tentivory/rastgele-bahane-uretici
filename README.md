# Rastgele Bahane Üretici

## Bu Proje Nedir?

Bu, insanlık tarihinin en önemli icadıdır. Artık geç kalmak, ödev teslim etmemek, toplantıya katılmamak için bahaneler üretmek zorunda değilsiniz. Bu açık kaynaklı, tamamen ücretsiz, sonsuz ölçeklenebilir motor sizin yerinize düşünür.

Bilim insanları (yani ben) yıllarca bu algoritma üzerinde çalıştı. Kuantum rastgelelik, Türk kültürünün derinliklerinden gelen absürt düşünce yapısı ve biraz da şans bir araya geldi.

## Nasıl Kullanılır?

```bash
python bahane_uretici.py
```

Ve işte! Hayatınız kurtuldu. Artık şefiniz size kızamayacak çünkü bahane bilimsel olarak doğrulanmış absürtlüktedir.

## Özellikler

- %100 gerçek (olmayan) bilimsel temel
- Sonsuz bahane havuzu (aslinda 10 tane ama hissettirmez)
- Türkçe optimized
- Hiçbir patates içermez (garanti)

## Uyarı

Bu yazılımı kullanarak üretilen bahanelerden dolayı işten atılma, not düşürme veya evlilik sorunlarından geliştirici sorumlu tutulamaz. Kullanıcı riski kendisi alır.
